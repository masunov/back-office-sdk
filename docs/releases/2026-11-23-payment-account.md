## Release notes: счёт для проведённой выплаты

### Что изменилось

- FinanceRequests::attachPaymentAccount формирует запрос на списание по проведённой выплате.
- Ответ BackOffice содержит исходный платёж и связанное движение.
- Миграции не требуются.

### Инфраструктура

Не требуется. Новых секретов нет.

### Переменные .env

Не требуются.

### Порядок действий

1. Выкатить BackOffice с API привязки выплаты, затем обновить SDK у потребителей.
2. Разовые команды не требуются.
3. Проверить, что привязка создаёт одно списание и сохраняет сумму оплаченного по обязательству.
4. Сообщить потребителям о новом методе.

### Откат

Вернуть предыдущую версию SDK. Обработать отправленные запросы перед откатом потребителей.
